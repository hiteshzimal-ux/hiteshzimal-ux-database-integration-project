# Database Integration Project

## DecodeLabs Project 3

### Features

- MongoDB Integration
- Mongoose ODM
- CRUD Operations
- Express REST API
- Validation
- Error Handling
- Environment Variables

### Installation

```bash
npm install
```

### Start MongoDB

```bash
mongod
```

### Run Project

```bash
npm run dev
```

### API Base URL

```text
http://localhost:5000/api/users
```

### Endpoints

| Method | Endpoint | Description |
|----------|----------|----------|
| POST | /api/users | Create User |
| GET | /api/users | Get All Users |
| GET | /api/users/:id | Get User |
| PUT | /api/users/:id | Update User |
| DELETE | /api/users/:id | Delete User |

### Database Schema

User

- name
- email
- age
- createdAt
- updatedAt

### Technologies

- Node.js
- Express.js
- MongoDB
